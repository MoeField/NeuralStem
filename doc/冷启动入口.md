## 1. 项目是什么

Android 原生「本地 AI 音轨分离播放器」（EE5415 个人项目）：导入单曲 → **本地离线** AI 分离
（人声/伴奏，或 4 轨：人声/鼓/贝斯/其他）→ 多轨同步播放 + 各轨音量/静音/独奏 → 变速变调 + 波形拖动。

- 需求：`doc/guide.md` ｜ 技术栈：Kotlin + Compose(M3) + Media3/ExoPlayer + sherpa-onnx/ONNX
- minSdk 23 / targetSdk 37 ｜ NDK `30.0.16248370` + CMake `4.1.2`

### 6.1 测试工具（devtools）
```bash
# 命令总线（adb 驱动，不重建 Activity；Action 见 TestCommandBus.helpText）
adb shell am start-service -n pub.miku.neuralstem/.devtools.TestCommandService --es cmd help
#   cmd: help/load/play/toggle/seek/clear/next/prev/queue/eq/inmt/exitsmt/togglesep
# 测试面板（按钮 + 屏上日志；截图即证据，避开 vivo 吞 logcat）
adb shell am start -n pub.miku.neuralstem/.devtools.TestPanelActivity
```

### 6.2 环境坑（真机）
- **vivo ROM 丢 manifest 广播** → 测试用 `am start-service`（非 broadcast）。
- **vivo/Android16 吞 app 的 logcat** → 用**测试面板屏上日志** / `dumpsys` / 产物取证。
- **vivo 安装弹窗**（坑 52）：`adb install` 卡在 `PackageInterceptActivity` → 可用坐标点
  “已了解风险” + “继续安装”，或用户手点。
- **`adb input tap` 对 Compose 小控件（chip）不稳** → 大目标（底栏/按钮）通常可点；小控件靠手动/命令总线。
- **BF00A 模型需 push 到私有目录**（坑 41）：`run-as <pkg> sh -c 'cat > files/.../x.onnx'`。

### 6.3 设备
- **BF00A**（蓝狐，中端）serial：USB `TLF2609A004328` / 无线 `adb-TLF2609A004328-pQOqTm...tcp`
