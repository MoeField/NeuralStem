# NeuralStem 演示视频分镜脚本（alpha v0.1.0-alpha）

> 用途：录制项目演示视频（guide §5.2 唯一缺的交付物）。
> 门控：用户明确「**可发布版本完工后**才做演示视频」——本脚本先备好，随时可用。
> 建议时长 **2–3 分钟**；全程**竖屏真机**（BF00A），横屏/深色可在最后各闪一下。

---

## 0. 开场（5s）
- 画面：App 图标 → 启动页（播放器空态）。
- 旁白/字幕：**「NeuralStem —— 本地 AI 音轨分离播放器，全部离线。」**

## 1. 导入 + 播放 + 波形（15s）
1. 空态点「导入音频」→ 选一首歌（如 katyusha.mp3）→ 自动播放。
2. 字幕：**「SAF 导入，支持 mp3/wav/flac/aac」**
3. 拖动转盘外环波形 → 实时跳转。
4. 字幕：**「波形拖动即跳转；已播/未播双色」**

## 2. 变速 + 变调（15s）
1. 竖滑条把速度从 1.0× 拖到 1.5×（音高不变）。
2. 音高旋钮 +3 半音（速度不变）。
3. 字幕：**「变速不变调 / 变调不变速，实时生效不中断」**

## 3. 本地 AI 分离（30s，核心）
1. 点底栏「分离」。
2. 选 **2 轨 · ⚡ 快速**（字幕：**「按设备 benchmark 推荐实时档」**）。
3. 展示分离进度 %（字幕：**「本地推理，完全离线」**）。
4. 分离完成 → 自动切多轨 / 或回播放页拨「分离开关」。
5. 字幕：**「Spleeter 2-stem，真机 ~7.9× 实时（4 分钟歌约 30s）」**

## 4. 多轨混音（25s，亮点）
1. 进「混音」页：两条轨（人声 / 伴奏）。
2. 把人声拉到 0 → 只剩伴奏（字幕：**「各轨独立音量」**）。
3. 人声轨「独奏」→ 只剩人声（字幕：**「静音 / 独奏」**）。
4. 回播放页：转盘外环**多色叠加波形**（字幕：**「各轨波形按颜色叠加（F5.1）」**）。
5. 拖动波形跳转，两条轨同步（字幕：**「多轨 seek 严格对齐」**）。

## 5. EQ（10s）
1. 「混音」页 EQ：拉低/拉高频段（字幕：**「5 段均衡，单/多轨均可用」**）。

## 6. 后台播放 + 后台分离（15s，N4/G-4）
1. 播放中按 HOME → 下拉通知栏看到媒体通知（字幕：**「切后台/锁屏继续播」**）。
2. 触发一次分离后立即 HOME → 通知栏出现「音轨分离」进度通知。
3. 字幕：**「分离任务前台化，后台不降频」**

## 7. 收尾（10s）
1. 横屏闪一下（字幕：**「横屏适配」**）；系统深色模式闪一下（字幕：**「跟随系统深色」**）。
2. 结束画面：**「NeuralStem · alpha 0.1.0-alpha · 完全离线」**
3. 字幕：**「已知限制：Spleeter 2019 模型有渗漏；4 轨/Demucs 较慢；边分离边播仅快速档」**

## 录制小抄（命令；非 UI 通道便于复现关键状态）
```bash
ADB=/Volumes/SA500/Library/Android/sdk/platform-tools/adb; S=TLF2609A004328; PKG=pub.miku.neuralstem
# 多轨直接载入（录屏用）
$ADB -s $S shell "am start -n $PKG/.MainActivity --es mt_vocals <vocals.wav> --es mt_accomp <accomp.wav> --ez auto_play true"
# 屏幕常亮
$ADB -s $S shell "svc power stayon true"
# 录屏
$ADB -s $S shell screenrecord /sdcard/demo.mp4 --time-limit 180
```

## 素材准备
- 一首有人声的歌（推荐 katyusha.mp3 / 太空旅行.mp3）
- 模型已 push（`files/sherpa/*.onnx`，重装后需重推）
- 建议提前跑过 benchmark（避免首启检测弹窗打断）
